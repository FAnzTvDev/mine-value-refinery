# MINE / STAGE 04 — FORGE

Write a one-page offer using **Buyer; Scope; Price hypothesis; Rights; Path; Next Step**. State deliverables, exclusions, support boundaries, approval requirements, payment/booking status and refund terms if established. Identify what is legally or commercially uncertain; don't invent active checkout, licensing authority, conversion metrics or clients. Provide a basic buyer interview script and first test price, clearly as proposal.
