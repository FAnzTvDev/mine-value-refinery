# MINE Visibility

## Purpose
Answer one question: when buyers ask the AIs, do they name you? Then produce the ranked fix list. This is the Vibe SEO game — rank #1 in the answers, not just the blue links.

## When to use
- User asks about AI search visibility, GEO, "rank on ChatGPT," or being cited by AI.
- Brand-build clients who need a visibility audit.
- Any MINE pipeline step where discoverability is the goal.

## The 5-prompt audit
Run these against ChatGPT, Claude, and Perplexity (ask the user to run them, or run them if you have browsing):
1. "Who are the best [category] for [buyer] in [market]?" (e.g. "best content studios for artists in Atlanta")
2. "What does [brand] do?"
3. "Compare [brand] vs [competitor]."
4. "Where should I [buy-intent action]?" (e.g. "where should I book a reel shoot")
5. "What are people saying about [brand]?"

Score: named / cited / linked / invisible — per engine, per prompt.

## The fix list (ranked)
1. **Search Console first** — connect it, find queries you already surface for. Free, and it's the data everything else stands on.
2. **Topical authority** — clusters of content around the money topics, internally linked. One orphan page never gets cited.
3. **Buy-intent keywords** — target the searches closest to a sale, not vanity traffic.
4. **Information gain** — every page must say something new: real numbers, real experience, real data. AIs cite what they can't find elsewhere.
5. **Be the answer** — Q&A blocks, direct definitions, quotable lines. Write the sentence you want quoted.
6. **Proof pages** — about page that says what you sell and who it helps, statistics/results page, money pages in the footer.
7. **Citation outreach** — get on the "best of" lists and roundups the AIs already read.
8. **Re-scan monthly** — visibility is a loop, not a task.

## Rules
- Never promise a #1 ranking — report what's observed, fix what's fixable.
- Original data beats optimization. If the brand has real numbers, those become the content.
- Every fix must be reviewable: the user approves before anything publishes.
- Report per-engine — ChatGPT, Claude, and Perplexity behave differently.

## Workflow
1. Take the brand, category, buyer, and market.
2. Run (or hand over) the 5-prompt audit across the engines.
3. Score the audit into a simple table: prompt × engine → named/cited/linked/invisible.
4. Produce the ranked fix list with the single highest-leverage fix first.
5. Offer to draft the fix content (proof page, Q&A blocks, statistics page).
