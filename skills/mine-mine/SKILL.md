# MINE / STAGE 01 — INVENTORY

Collect verifiable facts under **Story, Skill, Proof, Access, Archive, Systems**. For each item record: what it is, ownership/control, available evidence, source or location, confidence, and potentially useful audience. Do not turn relationships into property rights. Ask for source when unclear. Output a six-vein Value Map plus 3 candidate assets clearly labeled as hypotheses. Avoid inspirational filler.
