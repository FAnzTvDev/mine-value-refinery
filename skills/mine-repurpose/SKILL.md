# MINE Repurpose

## Purpose
One shoot becomes a month of content. Take a single source (long video, session, voice note, draft, idea) and cut it into a native distribution set for every platform — each piece rebuilt for its surface, never cross-posted blindly.

## When to use
- User has a long video, podcast, session recording, or long post.
- User says "repurpose this" or "turn this into content."
- Any MINE pipeline step after creation (the Distribute step of Create → Distribute → Community → Monetize).

## The distribution set
From one source, produce:

1. **3 shorts** (Reels/Shorts/TikTok) — each ONE idea, hook-first. Cut the 3 strongest standalone moments. Each gets its own hook from mine-hooks patterns; never reuse the same hook twice.
2. **1 carousel** (5–7 slides) — the method or breakdown version. Slide 1: the promise. Slides 2–6: one point each. Final slide: the CTA.
3. **1 text post** — the story or philosophy version, plain-spoken, line breaks for rhythm.
4. **Captions + hashtags** — per piece, platform-native (IG: short caption + hashtags; TikTok: minimal; YouTube: keyword-aware).

## Platform-native rules
- **Reels/TikTok/Shorts:** hook in first 3 seconds, captions burned in, 21–45 seconds, one idea.
- **Carousel:** designed for saves — each slide must stand alone.
- **YouTube:** title carries the search intent, description carries the links.
- **Text posts:** no hashtag stuffing, write like a person.

## Rules
- Never ship the same cut to every platform with the same caption — that's cross-posting, not repurposing.
- Every piece links back to the system: the CTA routes to the ecosystem (session, brand build, community) — never a dead end.
- Real numbers over adjectives. If the source has proof (views, revenue, results), it leads.
- Keep the creator's voice. Don't flatten everything into generic AI tone.

## Workflow
1. Ingest the source: identify the 3–5 strongest standalone ideas/moments.
2. Rank them by hookability (strongest first).
3. Build the 3 shorts (hook + moment + CTA each).
4. Build the carousel from the method/breakdown angle.
5. Build the text post from the story/philosophy angle.
6. Write captions + hashtags per piece.
7. Output as a checklist the user can shoot/post from, in platform order.
