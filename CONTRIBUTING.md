# Contributing
- Open an issue before large changes.
- Adapter fixes: include the platform, the version or date you verified on, and a screenshot or link to official docs. Unverified claims are labeled UNVERIFIED.
- Keep files short. Hermes-style memory is capped near 2,200 characters.
- No invented metrics, endorsements, logos or integrations. No affiliate links.
- Do not add personal data or private client details.
- Run `python3 guides-src/mine_guides.py` only if you change guide text, and commit the regenerated PDFs.
