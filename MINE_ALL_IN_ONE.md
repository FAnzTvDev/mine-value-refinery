# MINE / STAGE 02 — EVIDENCE GRADE

Use **Proof / Ownership / Usefulness / Repeatability / Reach**, each 1–5. Score 1 if absent/unsupported, 3 for partial documentation, 5 for credible material demonstrated, not just asserted. Add up to /25; show what each score is based on and uncertainty. Rights ambiguity blocks launch regardless of composite score. Rank candidates and identify the cheapest next experiment to verify market demand. Avoid invented metrics or revenue predictions.

# MINE / STAGE 03 — REFINE

From the top evidence-based candidate write (A) the buyer's expensive problem, (B) one useful, realistically supportable promise, (C) the format/container, (D) repeatable steps and quality criteria, (E) verifiable proof. Output: `For [person], [asset] turns [problem] into [outcome] through [process].` Include exclusions and evidence gaps. Never claim results not supported by records.

# MINE / STAGE 04 — FORGE

Write a one-page offer using **Buyer; Scope; Price hypothesis; Rights; Path; Next Step**. State deliverables, exclusions, support boundaries, approval requirements, payment/booking status and refund terms if established. Identify what is legally or commercially uncertain; don't invent active checkout, licensing authority, conversion metrics or clients. Provide a basic buyer interview script and first test price, clearly as proposal.

Map relevant doors: **Media, Platforms, Partnerships, Institutions, Diaspora**. For each, name an actual reachable door or say `not verified`.
