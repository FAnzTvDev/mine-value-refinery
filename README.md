# MINE: The Value Refinery AI Operating Kit

Portable instruction files that turn the AI you already use into a MINE coach: Mine, Grade, Refine, Forge, Move. By Julius Twum (Juice Bigfellow). Free site and self-assessment: https://thevybe.us/ai

This is a set of text files, not a hosted agent, API or integration. It does not give any assistant access to your accounts.

## Layout
- `core/` SOUL, MEMORY, INSTRUCTIONS, AGENT, CAPABILITIES (plus Hermes-sized MEMORY and USER)
- `adapters/` per-platform install notes: Claude, ChatGPT, Gemini, Grok, Copilot, Cursor, Codex, Hermes, Muse, OpenAI Dots, OpenClaw
- `skills/` ten skills (mine, grade, refine, forge, move, hooks, visibility, repurpose, access, brand)
- `workspace/` OpenClaw-style agent workspace (SOUL, IDENTITY, AGENTS, USER, MEMORY, TOOLS, HEARTBEAT, BOOTSTRAP)
- `guides/` branded setup PDFs; `guides-src/mine_guides.py` regenerates four of them (needs `reportlab`)
- `START_PROMPT.md`, `TEST_PROMPTS.md`, `MINE_ALL_IN_ONE.md`

## Use it
1. Run the free self-assessment at https://thevybe.us/ai#audit.
2. Use "Copy my SOUL" and "Copy my MEMORY" under your Value Map and paste them into your agent's soul and memory (Muse, Hermes, OpenClaw) or instructions (Claude, ChatGPT, Gemini).
3. Pick your platform in `adapters/` and follow it.

`core/MEMORY.md` and `workspace/MEMORY.md` are the founder's reference copy. Your own memory comes from your assessment.
