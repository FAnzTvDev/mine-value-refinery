# Claude installation

1. Make a Claude project, use START_PROMPT.md as project instructions.
2. Add SOUL.md, MEMORY.md, INSTRUCTIONS.md and the book PDF as project knowledge.
3. If your account supports Skills, install the directories inside `skills/` as individual skills in the supported interface. The bundled 10-skill ZIP is reference material, not guaranteed one-click installation.
4. Test persistence in a fresh project conversation; update MEMORY.md manually with approval.
5. Claude Code users can place CLAUDE.md in a working directory; that file alone does not set up the claude.ai web project.
References: https://support.claude.com/ and https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview
