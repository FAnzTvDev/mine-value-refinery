# Grok installation

1. At https://grok.com, create a dedicated MINE conversation or Project if available on your plan.
2. Upload START_PROMPT.md, SOUL.md, MEMORY.md, INSTRUCTIONS.md, the playbook PDF and selected individual SKILL.md files.
3. Ask Grok to state which attachments it read and whether it can persist the instructions in a new chat; do not assume it will.
4. For Grok Build code projects, AGENTS.md / CLAUDE.md can supply project instructions if supported and trusted. Web chat is a separate environment.
5. Verify connectors individually; there is no assumed access to social, messages, or publishing.
References: https://docs.x.ai/grok/faq and https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/12-project-rules.md
