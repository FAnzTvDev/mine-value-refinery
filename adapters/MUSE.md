# Muse (Meta) installation
Muse runs in Meta's cloud and keeps its persona and memory as text files in an OpenClaw-style workspace. Reports disagree on how much of them you can edit in the app; test it.

Best path (after the assessment)
1. Finish the free self-assessment at thevybe.us/ai#audit and generate your Value Map.
2. Press "Copy my SOUL (Muse)". In Muse, open the soul file, back it up, select all, paste, save.
3. Press "Copy my MEMORY (Muse)". In Muse, open the memory file, back it up, select all, paste, save. It holds your asset, buyer, rights, grade and next 72-hour move.
4. Add IDENTITY.md and AGENTS.md from workspace/ if you can edit more files. Keep Meta's purchase approvals and activity log on.
5. Start a new chat so the files reload.

If the files are locked: paste START_PROMPT.md as your first message, then paste your MEMORY text into the chat.
Meta's Model API is separate: put standing rules in a developer message.
Optional: use HEARTBEAT.md as a recurring daily check on your 72-hour plan, approval required before any action.
