# ChatGPT installation

1. Create a project called MINE — The Value Refinery.
2. Add SOUL.md, MEMORY.md, INSTRUCTIONS.md, AGENT.md, playbook PDF, and the skills ZIP/files as project sources where supported.
3. Paste the instructions in START_PROMPT.md into the project's instructions area.
4. Open a new project chat and run TEST_PROMPTS.md.
5. For reusable custom assistants, consider a Custom GPT where available; project files do not automatically create callable Skills or long-term structured memory.
6. Re-upload the dated approved MEMORY.md when material facts change; do not rely on implicit cross-account sync.
