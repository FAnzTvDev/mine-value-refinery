# OpenAI Dots installation
Dots is an always-on agent in OpenAI's cloud. Its memory lives on OpenAI's side and is not an editable file; clearing it means deleting the dot. Give it a standing instruction built from SOUL.md and AGENTS.md (five stages, six veins, evidence labels, approval rules), keep your own copy of MEMORY.md, and set it to ask before buying, sending, booking or posting.
