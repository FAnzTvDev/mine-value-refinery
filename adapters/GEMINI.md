# Gemini installation

1. Open https://gemini.google.com and use a persistent workspace/Gem where available.
2. Paste START_PROMPT.md into its instruction field, upload SOUL.md, MEMORY.md, INSTRUCTIONS.md and the playbook where supported.
3. Use individual SKILL.md files as referenced workflows unless the chosen Gemini developer environment explicitly supports that format.
4. Check that new conversations can recall the files; there is no automatic cross-provider memory sync.
5. Review Drive/Gmail access and privacy permissions separately.
