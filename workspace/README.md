# MINE Agent Workspace

Drop-in workspace files for personal agents that use the OpenClaw-style layout: SOUL.md, IDENTITY.md, AGENTS.md, USER.md, MEMORY.md, TOOLS.md, HEARTBEAT.md, BOOTSTRAP.md.

BACK UP your agent's current files before replacing anything.

## Muse (Meta)
Run the free assessment at thevybe.us/ai#audit, then use Copy my SOUL (Muse) and Copy my MEMORY (Muse) under your Value Map. Paste each over Muse's soul and memory files (back up first). This folder's MEMORY.md is the founder's reference copy; your own memory comes from your assessment. Add IDENTITY.md and AGENTS.md if Muse lets you edit more files. If the files are locked, paste START_PROMPT.md, then your MEMORY text, into the chat.

## OpenClaw
Copy all files into the agent's workspace folder. HEARTBEAT.md runs on the agent's heartbeat (every 30 minutes by default); keep it short and keep isolated sessions on to save tokens.

## Hermes Agent
SOUL.md goes in ~/.hermes/SOUL.md. MEMORY.md and USER.md go in ~/.hermes/memories/. MEMORY.md must stay near 2,200 characters and USER.md near 1,375. Skills: add the MINE skills from the kit. Offline: run a local model through Ollama and turn off web tools.

## OpenAI Dots
Dots keeps memory on OpenAI's side and it cannot be edited as a file. Give it the short start prompt and the five stages as standing instructions, and keep your own copy of MEMORY.md.

## Grok Bot
Use the skills and a start message. Memory is not documented as editable.

Always review before it sends, posts, buys or pays.
