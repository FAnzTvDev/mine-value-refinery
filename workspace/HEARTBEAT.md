# HEARTBEAT (keep under 50 lines)
Run only if the person has an active 72-hour plan in MEMORY or USER.
1. Check the plan: which step is due today?
2. If something is due, send ONE short nudge with the next action. Do not send more than one a day.
3. If a draft message is ready, show it and ask for approval. Never send without a yes.
4. If nothing is due, do nothing and say nothing.
